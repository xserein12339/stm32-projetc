### 1.1 ARM交叉编译链工具下载

[下载地址](https://github.com/xpack-dev-tools/arm-none-eabi-gcc-xpack/releases/tag/v14.2.1-1.1/)

```bash
sudo mkdir -p /opt/xpack-gcc
sudo tar xzf xpack-arm-none-eabi-gcc-14.2.1-1.1-linux-x64.tar.gz -C /opt/xpack-gcc --strip-components=1
echo 'export PATH="/opt/xpack-gcc/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### 1.4 OpenOCD与pyOCD调试工具下载

#### 1.4.1 安装工具

```bash
# OpenOCD（用于 ST-Link V2）
sudo apt update && sudo apt install -y openocd

# pyOCD（用于 CMSIS-DAP）
pip3 install pyocd --upgrade --break-system-packages
```

#### 1.4.2 配置 udev 规则

非 root 用户访问 USB 调试器必须配置权限，否则烧录/调试时会报 `Permission denied`。

```bash
# OpenOCD 自带 ST-Link 规则
sudo cp /lib/udev/rules.d/60-openocd.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger

# 验证
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg -c "init; exit"

# pyocd 自带了 udev 规则文件，复制到系统目录
sudo cp $(python3 -m pyocd.cmd udev --show-path 2>/dev/null || echo "/usr/local/lib/udev/rules.d/50-pyocd.rules") /etc/udev/rules.d/50-pyocd.rules 2>/dev/null

# 验证
pyocd list
```
